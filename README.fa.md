# سرور ورتکس RayZen

[English](README.md)

**امنیت تونل:** در پروتکل فعلی StormDNS/Vortex، داده‌های پاسخ DNS از سرور در خود تونل رمزگذاری یا اعتبارسنجی نمی‌شوند، حتی اگر AES-GCM برای درخواست‌ها انتخاب شده باشد. برای داده‌های حساس از برنامه‌ها و وب‌سایت‌های دارای TLS استفاده کنید؛ خود تونل محرمانگی و اعتبارسنجی سرتاسری را تضمین نمی‌کند.

سرور تونل DNS سریع برای برنامهٔ اندرویدی **RayZen Vortex-53** (نسخهٔ ۱.۴.۰ یا تازه‌تر) که با یک فرمان روی سرور مجازی لینوکسی نصب می‌شود و در حدود یک دقیقه آماده است.

- **سریع‌تر، با تأخیر کمتر و قطعی کمتر:** پاسخ‌دهی بهینه (پینگ‌های نگه‌داشت بدون رفت‌وبرگشت اضافه پاسخ می‌گیرند)، تنظیم خودکار بافر UDP و BBR در هسته، و نگهبانی که فقط وقتی پاسخ واقعی DNS قطع شود سرویس را دوباره راه می‌اندازد.
- **چند دامنه:** می‌توانید دامنهٔ بیشتری به همین سرور بدهید. برنامه همه را می‌آزماید، سریع‌ترین را به کار می‌برد و اگر یکی بسته شد سراغ بقیه می‌رود.
- **بدون کامپایل روی سرور:** فایل آمادهٔ `linux/amd64` دانلود و پیش از اجرا با SHA-256 بررسی می‌شود.
- **ارتقای درجا:** اگر سرور قدیمی Vortex-53 روی همان سرور باشد، ارتقا می‌یابد و کلید و دامنه‌اش حفظ می‌شود.

## پیش‌نیازها

- سرور مجازی با IPv4 عمومی و لینوکس دارای systemd (‏Ubuntu 20.04 به بالا یا Debian 11 به بالا)، پردازندهٔ **x86_64**.
- پورت UDP 53 از اینترنت در دسترس باشد (در پنل فایروال ارائه‌دهنده هم باز کنید).
- دامنه‌ای که DNS آن را خودتان تنظیم می‌کنید.

## ۱. رکوردهای DNS

یک دامنهٔ تونل انتخاب کنید، مثلاً `t.example.com`، و در پنل DNS دامنه دو رکورد بسازید:

</div>

| name | type | value |
|---|---|---|
| `ns.example.com` | A | IP سرور |
| `t.example.com` | NS | `ns.example.com` |

<div dir="rtl">

ممکن است چند دقیقه طول بکشد تا اعمال شود.

## ۲. نصب

</div>

```bash
curl -fsSL https://github.com/MattyMatinSys/RayZen-Vortex-Server/releases/latest/download/install.sh | sudo bash -s -- --domain t.example.com
```

<div dir="rtl">

در پایان یک پیوند `vortex://p/…` چاپ می‌شود. در برنامه «افزودن ← چسباندن» را بزنید (یا پیوند را روی گوشی باز کنید).

گزینه‌های بیشتر نصب: `--domain` (چندبار)، `--port 53`، `--ip PUBLIC_IP`، `--name "نام پروفایل"`، `--ns-host ns.example.com`، `--version X.Y.Z`، `--from DIR` (نصب بدون اینترنت)، `--yes`، `--no-dns-check`، `--no-tune`.

## ۳. مدیریت

پس از نصب، همین اسکریپت با نام `vortexctl` در دسترس است:

</div>

```bash
sudo vortexctl link                       # نمایش دوبارهٔ پیوند اتصال
sudo vortexctl status                     # وضعیت سرویس، شمارنده‌ها و آزمون واقعی تونل
sudo vortexctl check-dns                  # بررسی تنظیم DNS دامنه
sudo vortexctl add-domain t2.example.net  # یک دامنهٔ دیگر (سپس پیوند تازه را در برنامه بچسبانید)
sudo vortexctl remove-domain t2.example.net
sudo vortexctl update                     # تازه‌ترین نسخه، بررسی‌شده، سپس راه‌اندازی دوباره
sudo vortexctl rotate-key                 # کلید تازه: همهٔ پیوندهای قبلی از کار می‌افتند
sudo vortexctl backup | logs | uninstall [--purge]
```

<div dir="rtl">

پس از `add-domain` پیوند تازه را دوباره در برنامه بچسبانید: سرور ذخیره‌شده فقط دامنه‌های تازه را می‌گیرد و نام و تنظیم آن عوض نمی‌شود.

## نصب‌کننده چه چیزهایی را تغییر می‌دهد

`/usr/local/bin/vortex-server`، `/usr/local/sbin/vortexctl`، `/etc/vortex-server/`، `/etc/systemd/system/vortex-server.service`، `/etc/sysctl.d/90-vortex-server.conf`، کاربر سیستمی `vortex-server`، و (فقط اگر برای آزاد کردن UDP/53 لازم باشد) شنوندهٔ محلی `systemd-resolved`. اگر `ufw` یا `firewalld` فعال باشد، UDP/53 باز می‌شود.

## محدودیت‌ها

- فقط linux/amd64.
- پیوند، کلید سرور را در خود دارد؛ فقط با کسانی که به آن‌ها اعتماد دارید به اشتراک بگذارید.
- سرعت به ریزالورهایی بستگی دارد که شبکهٔ گوشی اجازه می‌دهد؛ در شبکهٔ پرفیلتر یک دامنهٔ دوم اضافه کنید و از اسکنر ریزالور برنامه کمک بگیرید.
